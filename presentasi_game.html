POS 01 • LATAR BELAKANG

Hybrid Markov Chain-Based Dynamic Scheduling (HMCDS)

Jurnal: Khaledian et al. (2025), Sustainable Computing: Informatics and Systems Vol. 45, Article 101077.
Tujuan: Mengatasi masalah penjadwalan tugas IoT di lingkungan Fog–Cloud tanpa membuat server overload.

1. Load Instability

Beban tidak merata memicu kemacetan (bottleneck) di node Fog.

2. Makespan & Delay Tinggi

Antrean panjang berbahaya untuk aplikasi real-time (medis, otonom).

3. Underutilization VM

Sebagian VM penuh, sebagian lain menganggur sehingga boros energi.

SOLUSI HMCDS
Gabungkan Markov Chain (prediksi beban sebelum penuh) + AOA (optimasi penjadwalan global).
POS 02 • ARSITEKTUR 3 LAPIS

Arsitektur Fog–Cloud & Peran CF_Manager

1. IoT / Sensor Layer

Mengirim permintaan tugas dari sensor & perangkat pintar.

2. Fog Layer (CF_Manager)

15 VM (100–2.800 MIPS, BW 1 GB/s). Dekat user, latensi rendah.

3. Cloud Layer

2 Data Center, 40 VM (3.000–5.000 MIPS). Kapasitas komputasi besar.

Cara CF_Manager Memilah Tugas:

  • Real-Time: Wajib diproses di Fog Layer terdekat agar latensi minimal.
  • Non-Real-Time: Boleh diproses di Fog maupun Cloud.
  • Ketergantungan: Tugas independent jalan paralel; dependent pakai DAG.
POS 03 • TAHAP 1: MARKOV CHAIN

Prediksi Beban VM dengan Markov Chain

Markov Chain bersifat memoryless (status $t+1$ hanya melihat status saat ini $t$), sehingga sangat ringan tanpa perlu training ML berat.

1. Beban VM & Matriks Transisi: $$L_i(t) = \lambda_1 E_i(t) + \lambda_2 W_i(t), \quad \text{LOAD}(i) = \sum L_k(t)$$ $$P_{ij}(t) = P\{X_{n+1} = j \mid x_n = i\}$$
2. Tiga Status Prediksi VM:
  • V2 = U (Low Load): $P_{ij} \le \text{MIN}$ → Prioritas penerima tugas.
  • V1 = N (Normal): Kondisi aman & stabil.
  • V3 = O (Overloaded): $P_{ij} \ge \text{MAX}$ → Diblokir & migrasi tugas!
POS 04 • TAHAP 2: AOA

Optimasi Penjadwalan Menggunakan AOA

Arithmetic Optimization Algorithm (AOA) mencari pemetaan Task → VM terbaik menggunakan 4 operator aritmatika ($\div, \times, -, +$) yang dikendalikan oleh $\text{MOA}$ dan $\text{MOP}$.

Fungsi Tujuan (Minimalkan Makespan, Delay, & Energi): $$\text{ETC}_{ij} = \frac{T_{len}^i}{VM_{pow}^j}, \qquad \text{Cost}_{\text{fog}} = \min\left(\max_j \sum_i \text{ETC}_{ij}\right), \qquad F = \alpha D + (1-\alpha)E$$

Eksplorasi ($r_1 > \text{MOA}$)

Memakai Pembagian ($\div$) & Perkalian ($\times$) untuk melompat jauh mencari kandidat VM baru secara global.

Eksploitasi ($r_1 \le \text{MOA}$)

Memakai Pengurangan ($-$) & Penjumlahan ($+$) untuk menyempurnakan solusi terbaik best(x).

📚 Glosarium Tanya Jawab (Q&A Dosen)

  • Makespan: Total waktu dari tugas pertama dimulai hingga tugas terakhir selesai.
  • Delay (Latency): Waktu tunda sejak tugas dikirim perangkat IoT hingga selesai diproses.
  • Throughput: Jumlah tugas selesai per satuan waktu ($\text{Throughput} = \sum \text{ExeTime}(t_i)$).
  • PIR: $\text{PIR}(\%) = \frac{Y - Y'}{Y} \times 100\%$ (persentase peningkatan performa terhadap pembanding).
  • Memoryless Property & MIPS: Status berikutnya hanya bergantung pada status saat ini; MIPS = Million Instructions Per Second.
